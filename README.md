# SmartCorrect AI

### AI-Powered Autocorrection and Writing Assistant

SmartCorrect AI is a web-based AI writing assistant that helps users improve spelling, grammar, punctuation, clarity, and overall writing fluency.

The application uses Google Gemini AI to analyze user-written text, identify errors, provide corrections, and generate an improved version while preserving the user's original meaning.

---

## ✨ Features

- 🤖 AI-powered spelling and grammar correction
- ✍️ Punctuation and sentence improvement
- 📊 AI-generated writing quality score
- 🔍 Detailed correction analysis
- 📝 Before-and-after text comparison
- 🎯 Multiple writing modes:
  - Standard
  - Professional
  - Casual
  - Academic
  - Concise
- 💡 AI-generated writing suggestions
- 📋 Copy corrected text
- 🔄 Replace original text
- 🕘 Recent correction history
- 💾 LocalStorage-based history
- ⌨️ Ctrl + Enter shortcut for quick correction
- ⚡ Loading and error states
- 📱 Responsive design for desktop, tablet, and mobile

---

## 🎯 Project Objective

The objective of SmartCorrect AI is to design an AI-driven autocorrect tool that improves text accuracy and fluency while reducing errors in typing and communication.

Unlike a basic spell checker, SmartCorrect AI analyzes the context of the complete text and provides improvements for spelling, grammar, punctuation, clarity, and writing style.
